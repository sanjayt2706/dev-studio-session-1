# Dev Studio — Session 1

Workshop material and practice code for the first development session conducted through **Dev Studio**.

## Purpose

This repository is designed as a learning resource for students beginning their software-development journey. It keeps the examples and exercises from the session in one place so participants can revisit, run, and extend them.

## Topics

The examples in this repository are intended to support hands-on learning around programming and development fundamentals.

## How to Use

Clone the repository and open the project in your preferred IDE/editor.

```bash
git clone https://github.com/sanjayt2706/dev-studio-session-1.git
cd dev-studio-session-1
```

Run the examples using the language/toolchain used by the individual exercise.

## Why this repository exists

Dev Studio follows a practical, peer-learning approach: learn a concept, write a small example, debug it, and build on it.
